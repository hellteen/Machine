# Машина выбора

Интерактивная симуляция искусственной жизни, исследующая возникновение выбора и адаптивного поведения в изменяющейся физической среде.

## О проекте

«Машина выбора» - это интерактивный программный комплекс, в котором пользователь создаёт условия среды, запускает симуляцию и наблюдает за тем, как организмы принимают решения, взаимодействуют со средой, размножаются и изменяют свои стратегии между поколениями.

## Запуск приложения

Откройте папку Machine Select и запустите exe файл Machine.

Выберите небесное тело и начните симуляцию живых организмов. Следите за их развитием, анализируйте, собирайте данные и переносите их в удобную Excel таблицу.

## Функционал

При запуске загружается JSON с данными выбранной планеты. SimulationManager принимает эти данные и запускает симуляцию. 

Затем через определённый промежуток времени создаётся очередной шаг симуляции - тик.
На каждом тике DecisionEngine анализирует состояние организма и окружающей среды и выбирает, что организм должен делать: двигаться, искать ресурсы, ждать или размножаться.

После этого ActionSystem выполняет выбранное действие и изменяет данные организма и планеты: энергию, здоровье, голод, возраст, положение, количество ресурсов и другие параметры. Если организм может размножаться, EvolutionSystem создаёт нового организма и немного изменяет его характеристики через мутации.
После обработки всех организмов SimulationManager удаляет погибших, добавляет новых, восстанавливает ресурсы планеты и обновляет показатели интерфейса. UI уже просто отображает эти данные: количество организмов, параметры планеты, события и положение организмов на сцене.
